# 🏠 NeoHouse CTF - Мастер-класс по WiFi безопасности
Ресурсы для проведения мастер класса по безопасности Wi-Fi на очной ставке NeoQuest 2025 (26.09)

> **"Ваша домашняя сеть уязвимее, чем кажется"**

Вы оказываетесь у стен современного ЖК "NeoHouse". Повсюду расклеены объявления с приглашением вступить в чат жильцов. Рядом виден WiFi **NeoLink_523**...

## 🎯 Сценарий атаки

### **Этап 1: OSINT и доступ к сети**
- 📱 Вступить в чат жильцов через QR-код
- 🔍 Найти владельца квартиры 523 и его номер телефона  
- 🔑 Подключиться к WiFi NeoLink_523 (пароль = номер телефона)

### **Этап 2: Сетевая разведка**
- 🔎 Просканировать сеть: `nmap -sn 192.168.1.0/24`
- 🖥️ Найти сервер с открытым портом 8080 (HTTP)
- 📊 Изучить сервисы: `nmap -SC -SV -T4 192.168.1.100`

### **Этап 3: Эксплуатация LFI уязвимости**
- 📁 На странице логов найти параметр `?file=`
- 🔓 Через LFI получить доступ к секретному файлу
- 🏆 Забрать флаг: `neowifi{lf1_f1l3_1nclu510n_4tt4ck_1337}`

### **Этап 4: MITM атака и перехват учетных данных**
- ⏱️ В логах заметить регулярные входы администратора
- ⚠️ Обнаружить отсутствие HTTPS
- 🕵️‍♂️ Провести ARP spoofing атаку:
  ```bash
  echo 1 | sudo tee /proc/sys/net/ipv4/ip_forward
  sudo arpspoof -i wlan0 -t 192.168.1.50 192.168.1.1
  sudo arpspoof -i wlan0 -t 192.168.1.1 192.168.1.50
  ```
- 📨 Перехватить логин/пароль администратора
- 🔐 Получить доступ к админке и второй флаг: ```neowifi{m1tm_p455w0rd_0r_t0k3n_1nt3rc3pt10n_0v3r_9000}```

## 🛠️ Технологии и уязвимости

### **Уязвимости демонстрируемые в стенде:**
- 🔓 Слабые пароли WiFi (номера телефонов)
- 📱 Утечка информации в чатах жильцов
- 🌐 LFI (Local File Inclusion) в веб-приложении
- 🔓 Отсутствие HTTPS и перехват трафика
- 🕵️‍♂️ ARP Spoofing и MITM атаки
- 🚪 Небезопасная аутентификация по HTTP

### **Инструменты для атаки:**
- ```nmap``` - сетевая разведка
- ```arpspoof``` - ARP спуфинг
- Python + Flask - уязвимый сервер
